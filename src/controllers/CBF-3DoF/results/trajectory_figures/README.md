# Cross-controller trajectory figures

This directory contains comparisons derived from retained closing and final-approach CBF campaigns. `selected_nominal_rollouts/` stores only the nominal rollout histories needed to reproduce the selected comparisons. Source CBF trajectories remain in their phase-specific evaluation directories.

`closing_and_final_approach_representative_trajectories_2x2.png` summarizes
both phases. `selected_seeds.json` identifies the selected controller and
evaluation seeds, and `constraint_and_control_figure_summary.json` records the
source artifacts used by the diagnostic figures.
