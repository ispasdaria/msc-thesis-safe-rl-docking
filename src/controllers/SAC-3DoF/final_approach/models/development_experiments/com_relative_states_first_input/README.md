# Center-of-Mass Observation Reward Development

This family contains early final-approach SAC experiments that used center-of-mass relative states as the first observation input. It records reward versions 1 through 28 for training seed 0. Most policies were trained for 50,000 steps; reward version 7 also has a 200,000-step run.

The family documents early reward and observation development and is not a retained policy campaign. Each model has a matching VecNormalize file with the same stem.

Related training logs and results are stored under the matching `com_relative_states_first_input` development directories.
