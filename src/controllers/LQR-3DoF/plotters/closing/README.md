# Closing-phase plotters

- `plot_closing_actuator_saturation.py` summarizes per-channel saturation across closing rollouts.
- `plot_closing_applied_commands.py` compares requested and applied commands for a representative history.
- `plot_closing_requirements.py` plots closing errors against the P3 handover tolerances.
- `plot_closing_sampled_stability.py` evaluates sampled-data spectral radius over several control intervals.
- `plot_closing_terminal_error_scatter.py` compares terminal rollout errors with the acceptance limits.
- `plot_lqr_closing_schedule_comparison.py` compares matched rollouts with fixed and scheduled axial references.
- `plot_representative_closing_trajectories.py` compares representative successful and timed-out rollouts.
