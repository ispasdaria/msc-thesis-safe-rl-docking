# Representative Rollout Histories

This directory contains selected `dt=0.1 s` trajectories used to illustrate
closing-controller behavior:

- seed 1: lateral-position timeout;
- seed 20: median-duration successful rollout;
- seed 41: representative successful rollout.

The compressed NumPy files contain time, state, error, target, and control
histories consumed by the representative-trajectory plotting script. They are
selected examples rather than an exhaustive evaluation dataset.
