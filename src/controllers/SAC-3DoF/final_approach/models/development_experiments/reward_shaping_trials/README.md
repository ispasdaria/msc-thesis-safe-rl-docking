# Docking-Port Reward-Shaping Trials

This family contains the first ten docking-port-observation reward variants. Reward versions 1 through 10 were trained for 100,000 steps with training seed 0.

Each model has a matching VecNormalize file. These policies document the reward-shaping sequence that preceded the reward-version-9 Optuna campaigns. They are retained as development history and are not final policy selections.

Related learning curves and rollout evaluations are stored under the matching `reward_shaping_trials` development results directory.
