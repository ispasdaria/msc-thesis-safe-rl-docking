# Representative Full-Mission LQR Rollouts

This directory contains selected histories from a full-mission LQR evaluation.
Each mission starts with the closing phase and enters final approach only after
the closing target is reached.

## Evaluation configuration

- Mode: `testing`
- Closing-controller time step: `1 s`
- Final-approach-controller time step: `1 s`
- Closing-phase duration limit: `12,000 s`
- Final-approach duration limit: `5,000 s`

## Selected histories

- `seed0000_first_closing_failure_failed_closing.npz` contains the first mission
  that failed during closing.
- `seed0001_first_full_success_success.npz` contains the first mission that
  completed both phases successfully.
- `seed0002_highest_closing_saturation_failed_closing.npz` contains the mission
  with the largest closing-controller saturation fraction.
- `seed0025_worst_closing_final_error_failed_closing.npz` contains the closing
  failure with the largest terminal error.
- `seed0074_highest_final_saturation_success.npz` contains the successful
  mission with the largest final-approach saturation fraction.
- `seed0144_typical_closing_timeout_failed_closing.npz` contains a
  representative closing timeout.
- `seed0152_median_full_success_success.npz` contains the representative median
  full-mission success.

Each compressed NumPy file stores the closing and final-approach time, state,
and command histories, the phase-transition state, target information, outcome
metadata, and actuator-saturation measurements. Final-approach arrays are empty
for missions that did not complete the closing phase.

The histories are generated by `evaluation/run_lqr_full_mission.py` and consumed by
`plotters/full_mission/plot_lqr_mission_rollouts.py`. They are selected diagnostic examples rather
than the complete evaluation dataset.
