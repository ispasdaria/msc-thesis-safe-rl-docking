# P3-Reach V12 Optuna Study

This group contains the V12 hyperparameter study using freshly initialized SAC policies and a 600,000-step maximum budget. The environment, reward, reset distribution, and nonterminal-safety semantics remain fixed while SAC optimization parameters vary.

Optuna trial numbers remain unchanged. The results contain the study database, trial table, evaluation metrics, and retained trial outputs; matching TensorBoard logs are under `../../logs/p3_reach_v12_optuna/`.
