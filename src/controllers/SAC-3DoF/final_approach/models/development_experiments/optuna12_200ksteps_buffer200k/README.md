# Optuna Trial 12 - 200k Steps, 200k Replay Buffer

This development run applies the selected Optuna trial-12 SAC hyperparameters to reward version 9 with a 200,000-step training budget and a 200,000-transition replay buffer.

The family contains final and best checkpoints for training seed 0. Both checkpoints have matching VecNormalize files. This configuration was evaluated during budget and replay-buffer development but was not retained as a final policy family.
